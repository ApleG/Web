# 西迁长卷 · 求是之路（1937—1946）

以浙江大学西迁为背景的互动叙事网页。

- 七幕选择，多结局与离队分支
- 选项随机排序，选择会改变后续剧情
- 每个结局后附一篇真实报道、访谈、报告文学或档案新闻的节选与原文链接
- 支持手机端浏览

## 在线访问

GitHub Pages：https://apleg.github.io/Web/

## 本地运行

双击 `index.html`，或在该目录启动任意静态文件服务器。

## 项目结构

```
.
├─ index.html
├─ css/style.css
├─ js/content.js   全部文案、剧情、选项、结局与延伸阅读
└─ js/game.js      交互、分支、结局与页面渲染
```

## 说明

本作品为“大学生思想文化素养”课程传播实践作品，历史框架依据公开校史资料，部分场景与对白为文学化创作。延伸阅读仅展示原文节选并标注作者、来源、日期与原链接，著作权归原作者与媒体所有。
